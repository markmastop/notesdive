# NotesDive 0.18.13 — Fullscreen PowerPoint and PDF presentations

Built 2 November 2026 for Apple Silicon macOS.

- PowerPoint and PDF viewers now include a presentation button that opens the current slide or page fullscreen.
- Navigate with arrow keys, Space, Page Up/Down, Home and End. Controls appear on pointer movement or keyboard focus; Escape returns to the current slide or page in the viewer.
- PDF pages fit entirely within the screen, including mixed portrait and landscape pages. The normal viewer retains its zoom setting after presenting.
- Presentation controls and fullscreen session handling are shared with the existing Marp viewer.

This download supports Apple Silicon macOS only. The app uses an ad-hoc signature and is not notarized. Existing PowerPoint rendering limitations apply: slides are static previews without animations or transitions. reMarkable folders remain read-only.
