# NotesDive 0.18.11 — Resume each project where you left off

Built 28 October 2026 for Apple Silicon macOS.

- Each project remembers its last view, selected folder and open document. Switching projects restores that project’s own location instead of returning to Overview or inheriting another project’s view.
- Project view filters, search and sorting are remembered separately for each project and library, including after restarting the app.
- Unsaved document edits are saved before switching projects. Locations are stored locally on this device; unavailable documents cannot be reopened.

This download supports Apple Silicon macOS only. The app uses an ad-hoc signature and is not notarized. reMarkable folders remain read-only. Existing PDF, presentation and reMarkable preview/export limitations continue to apply.
