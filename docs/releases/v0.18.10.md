# NotesDive 0.18.10 — Project creation shortcuts

Built 28 October 2026 for Apple Silicon macOS.

- New project notes use the selected local folder or subfolder, including a linked folder that differs from the default project destination. With no folder selected, they use the configured destination.
- Compact note, todo and link icon buttons sit beside project search.
- New todos append to TODO.md and new links append to LINKS.md in the project destination. Missing files are created; existing contents and existing case variants are preserved.

This download supports Apple Silicon macOS only. The app uses an ad-hoc signature and is not notarized. reMarkable folders remain read-only. Existing PDF, presentation and reMarkable preview/export limitations continue to apply.
