# NotesDive 0.18.12 — Aligned project panels

Built 28 October 2026 for Apple Silicon macOS.

- Project file, reMarkable, task and link panels share a responsive height with the document viewer, aligning their top and bottom edges.
- Folder trees, document lists and long task or link lists scroll within their panels. Overview panels keep their content contained while the project stream and reader remain independently accessible.
- Narrow windows stack the browser and reader with matching heights. Home, Files, Tasks, reMarkable, Projects and Settings were checked at desktop and compact window sizes in Chromium and WebKit.

This download supports Apple Silicon macOS only. The app uses an ad-hoc signature and is not notarized. reMarkable folders remain read-only. Existing PDF, presentation and reMarkable preview/export limitations continue to apply.
